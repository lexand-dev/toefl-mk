# Documentación de dominio

Este es un proyecto de contexto único.

Antes de trabajar sobre el dominio, lee `CONTEXT.md` y los ADR pertinentes en `docs/adr/` si existen. Usa los términos definidos allí. Si aún no existen, continúa sin exigir su creación.

Mientras no haya glosario o ADR, consulta la especificación funcional TOEFL, el documento de MVP y modelo de datos, y el esquema SQL de referencia. Distingue materiales, ítems evaluables, revisiones e intentos.
