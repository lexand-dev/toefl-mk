# Issue tracker: Markdown local

Las especificaciones y los tickets de este proyecto se guardan en `.scratch/`.

## Convenciones

- Una carpeta por iniciativa: `.scratch/<nombre>/`.
- Especificación: `.scratch/<nombre>/spec.md`.
- Tickets de implementación: `.scratch/<nombre>/issues/<NN>-<nombre>.md`.
- El estado se declara cerca del encabezado como `Status: <estado>`.
- Una especificación lista para ejecutar lleva `Status: ready-for-agent`.
- Las dependencias entre tickets se registran como `Blocked by: NN, NN`.
- Los comentarios se añaden bajo `## Comments`.

Publicar en el tracker significa crear o actualizar el archivo Markdown correspondiente.
